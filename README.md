# BandedPlusSpiked
Code to Reproduce the results in the paper titled as: MLE of  Banded, Spiked, High-Dimensional Clutter Covariance--A Convex Relaxation Approach

The SCNR plots were done using the code: BandedplusSpikedComputation.m.
Access the file Cofar.mat from the following link: <https://drive.google.com/file/d/1qZ7r7gqy4qUjccVDx8kKLkoLKNWBxm5G/view?usp=sharing>.
Plots for figure 2 were done using the code: EpsilonPlot.m.
